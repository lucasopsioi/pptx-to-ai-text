# PPT 转 AI 文本

把 `.pptx` 转成**带完整格式信息**的结构化文本，让 AI 能照着精确还原，而不是凭空想象版式。

只有一个文件：`PPT转AI文本.html`

---

## 怎么装到公司电脑（不需要传文件）

这个工具**本身就是纯文本**，所以不存在"传不出去/传不进来"的问题：

1. 用记事本打开 `PPT转AI文本.html`，全选复制
2. 在公司电脑上打开记事本，粘贴
3. 另存为 `PPT转AI文本.html`，**编码选 UTF-8**
4. 双击，用 Edge / Chrome 打开

不需要安装、不需要管理员权限、不需要联网、不需要 Python。

## 怎么用

把 `.pptx` 拖进页面 → 出一大段文本 → 点「复制全部」→ 粘给 AI。

文本开头自带一段**给 AI 的格式说明**，AI 读了就知道每个字段什么意思，不用你再解释。

### 选项

| 选项 | 作用 |
|---|---|
| 附还原说明 | 在开头加给 AI 看的格式约定（第一次用建议开） |
| 提取图表数据 | 把图表的系列名/类别/数值全部导出，AI 能重建图表 |
| 提取表格逐格格式 | 每个单元格的填充、四边边框、字号、对齐 |
| 包含空占位符 | 默认跳过没内容的占位符，减少噪音 |
| **紧凑模式** | 省略默认值、合并重复的表格格式。**页数多时必开** |
| 单位 | 厘米 / 英寸 / EMU 原始值 |

---

## 能提取什么

- **画布**：尺寸、比例、主题配色（accent1~6 等全部十色）
- **每个形状**：预设形状类型（含中文名）、位置 xy、宽高、旋转角、水平/垂直翻转
- **填充**：纯色 / 渐变（含每个色标位置和角度）/ 图案 / 图片 / 无
- **边框**：粗细 pt、颜色、虚线样式、端点、箭头
- **效果**：外阴影（模糊/距离/方向/颜色/不透明度）、内阴影、发光、柔化边缘、倒影
- **文字**：逐个 run 的字号、粗斜体、下划线、删除线、颜色、中英文字体分别、字距、上下标
- **段落**：对齐、行距、段前段后、项目符号、缩进层级
- **文本框**：垂直锚点、四边内边距、自动换行、自动缩放、竖排
- **表格**：行列数、每列宽、每行高、逐格文字与格式、合并单元格
- **图表**：图表类型（柱/折线/饼/面积/散点…）、堆积方式、每个系列的名称+颜色+类别+全部数值、图例位置
- **组合**：层级结构 + 组合内部坐标系
- **z 轴顺序**：形状编号即叠放顺序

## 不能提取什么

- **图片像素**——只给文件名、位置、尺寸。图片得你另外发给 AI
- **SmartArt 内部布局**——会降级成组合形状
- **动画、切换效果**
- **母版/版式继承的隐式格式**——只提取幻灯片上写死的；占位符会标注类型，让 AI 自己套模板
- **旧版 `.ppt`**——需先在 PowerPoint 里另存为 `.pptx`

**精度验证**：拿一份由 python-pptx 脚本生成的 PPT 做回归——提取出的颜色 `#1F6F8B`、阴影参数（不透明度 34%、模糊 0.08cm、距离 0.03cm、方向 90°）、表格列宽（2.34/6.65/3.25/3.25 cm）、字号字体，与源码逐项精确吻合。

**tokens 参考**：14 页复杂商务 PPT ≈ 2 万 tokens。给 AI 是够的。页数特别多就分批转。

## 技术说明

- `.pptx` 本质是个 zip，里面是 OOXML。工具用浏览器原生 `DecompressionStream('deflate-raw')` 解压，自己写了个 ZIP 中央目录解析器，**零第三方依赖**
- 需要 Edge / Chrome 100+（`DecompressionStream` 支持）
- 文件全程只在本机内存里处理，**不上传任何地方**，也不联网

> ⚠️ 但注意：你把生成的文本粘给 AI 时，文本会离开这台机器。工具本身不联网，之后怎么用是你自己的判断。

## 已知的坑（修过了）

- **关系路径有三种写法**：绝对 `/ppt/charts/chart1.xml`、相对 `../charts/chart1.xml`、同级 `chart1.xml`。最初只处理了相对形式，导致 27 个图表全部解析失败。现在用统一的路径解析器。
